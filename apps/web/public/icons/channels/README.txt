Official channel icons for the inbox avatar badge.

Put the icon files the platforms publish for integrations here, as square PNGs
(at least 64x64):

  messenger.png   — Meta Brand Resource Center, Messenger logo
  instagram.png   — Meta Brand Resource Center, Instagram glyph
  zalo.png        — Zalo brand/press kit

A missing file is fine: the inbox falls back to its generic badge for that
channel. Nothing else needs changing — deploy and the badge picks the file up.
