## Nếu muốn sửa

Sửa trực tiếp trong file `phu-de-app-review-v2.srt` (mở bằng Notepad), rồi trong CapCut:
xoá lớp phụ đề cũ → Captions → Add captions → Import file → chọn lại file → Export.

Nhớ để con trỏ timeline ở mốc **0:00** trước khi bấm "Add to track", nếu không phụ đề sẽ bị lệch.
